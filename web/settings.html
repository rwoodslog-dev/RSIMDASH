Connexion au PC (RSIM Agent)

  1. Sur le PC, lance RSIM Dash (raccourci du bureau).
  2. L'adresse s'affiche dans la fenêtre noire et dans le panneau (onglet Téléphone) : http://192.168.x.x:8888.
  3. Le téléphone doit être sur le même Wi-Fi que le PC. Astuce : IP fixe pour le PC dans ta box.
