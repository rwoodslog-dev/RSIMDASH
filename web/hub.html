Connecter le téléphone

Adresse à ouvrir dans Chrome sur le téléphone (même Wi-Fi) :
…
  1. Ouvre cette adresse dans Chrome.
  2. Menu ⋮ → Ajouter à l'écran d'accueil : l'icône RS DASH apparaît.
  3. Touche l'écran pour passer en plein écran ; appui long = menu (dash, orientation verrouillée).

Astuce : donne une IP fixe au PC dans ta box pour que l'icône du téléphone marche toujours.

Boutons du volant
